# 自动预测与模拟下注计划

## 目标

让自动化服务真正运行独立首发刷新，并在开赛前 24/12/6/1/0.5 小时各生成一次 AI 预测；每场自动模拟下注 100，模拟账户初始资金为 5000。

## 阶段

### 阶段 1：调度与配置
- 状态：完成
- 注册 `lineup` 任务；增加预测窗口和自动下注配置。

### 阶段 2：预测与下注链路
- 状态：完成
- 按窗口持久化执行标记，自动下注使用固定金额并保持幂等。

### 阶段 3：资金与测试
- 状态：完成
- 更新新账户默认资金、环境示例和最小关键测试。

### 阶段 4：验证
- 状态：完成
- 运行 Python 编译、自动化/资金相关测试并检查最终配置。

## 决策

- 自动预测按每个时间窗口单独记录，窗口内失败可重试，成功后不重复。
- 固定 100 仅由自动化调用传入；保留手动下注的既有行为。
- 下注仍要求预测产生可执行市场和有效赔率；余额不足时由账本拒绝，不能透支。
