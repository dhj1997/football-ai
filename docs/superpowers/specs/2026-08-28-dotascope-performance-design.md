# DotaScope 风格足球策略表现设计

## 目标

为现有足球预测系统增加可解释、可比较、可回溯的策略表现层，借鉴 DotaScope 的独立实验账本、三层指标、样本门禁和单场复盘思路。当前系统仍保持手动触发模型预测和纯模拟资金，不连接真实投注平台。

## 范围

- 每个模型拥有独立的虚拟账本；当前 GPT 与 DeepSeek 继续复用现有账户。
- 每个预测保存策略标识、策略版本、提示词/决策版本和证据快照标识。
- 每场比赛无论是否下注，都保留 `bet` 或 `no_bet` 决策及原因。
- 表现接口同时返回预测质量、市场/决策质量、组合/资金质量和样本门禁状态。
- 表现页增加策略上下文、门禁状态、拒绝下注数量和市场对照指标。

## 数据流

预测生成时固定 `evidence_snapshot_id` 和版本字段；市场决策产出候选市场、赔率、概率、优势、理论仓位；模拟账户只负责执行和结算。结算服务以比赛为预测样本，以已执行下注为组合样本，并使用收盘赔率存在时计算 CLV。表现报告不改写历史预测，只聚合不可变记录。

## 质量门禁

门禁输出 `status`、`mode`、`failures` 和各项样本计数。样本不足或市场对照不足时显示 `INSUFFICIENT_SAMPLE`/`SHADOW_ONLY`，不能因为短期 ROI 为正而自动提升为可靠策略。第一期只实现可计算的门禁字段，不改变现有下注资格；阈值集中在后端，便于后续用历史样本校准。

## 页面

表现页保留现有资金曲线和下注明细，新增：策略/模型版本信息、预测/决策/组合三层摘要、质量门禁徽章和不下注/拒绝计数。所有空值显示为“暂无样本”，不伪造收益或 CLV。

## 验证

- API 测试覆盖无结算样本、已结算样本、CLV 样本不足、门禁失败原因和版本字段。
- 现有下注、亚洲盘结算、手动预测和自动化测试必须继续通过。
- Web TypeScript、lint 和生产构建必须通过。

## 非目标

- 不实现 Dota 的地图/赛事模型、实时顺势策略或积分倍率。
- 不新增外部数据源，不修改当前预测概率生成方式。
- 不把样本不足的策略自动变成可执行或真实下注策略。
