# 首页赛程联赛标签设计

## 目标

首页继续使用按状态和开球时间排序的统一赛程列表，不恢复按联赛分组；每一场比赛必须直接显示所属联赛。

## 设计

- 在 `FixtureRow` 左侧时间区显示联赛标签，顺序为：开球时间、联赛、比赛状态。
- 标签使用现有 `leagueDot` 色点和克制的深色徽标样式，文字取 `fixture.league.name`。
- 球队对阵、赔率、证据和预测状态区域保持不变。
- 移动端和桌面端使用同一标签，不隐藏联赛名称。
- 列表仍按比赛状态与开球时间排序，不按联赛拆成多个卡片。

## 数据流

直接使用赛程列表 API 已返回的 `fixture.league.name` 和 `fixture.league_key`，不增加接口、数据库字段或新的映射逻辑。

## 失败与兼容

若联赛名称为空，显示 `fixture.league_key.toUpperCase()`，避免出现空白标签。标签使用固定最大宽度和截断，防止长赛事名称挤压球队对阵。

## 验证

- ESLint 和生产构建通过。
- 首页统一列表中每行都能看到联赛标签。
- 在桌面和窄屏宽度下检查球队名、赔率、证据状态无重叠。
- 部署后确认中超、西甲等不同联赛比赛均显示正确名称。
