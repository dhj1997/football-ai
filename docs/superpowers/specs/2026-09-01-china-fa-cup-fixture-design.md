# 中国足协杯赛程接入设计

## 目标

在比赛中心的今日、明日和历史列表中展示中国足协杯赛程与已提供的比分，并允许按“足协杯”筛选。足协杯不进入现有积分榜、三联赛历史回测或联赛绩效统计。

## 数据源

- TheSportsDB 联赛 ID `5525` 作为比赛中心的主赛程源，沿用现有按日期同步机制。
- API-Football 联赛 ID `171`（China FA Cup / FA Cup）加入适配器映射，用于足协杯结果和比赛详情证据的后续按需读取。
- 两个适配器统一使用应用内部联赛键 `cfa_cup`，对外展示名为“中国足协杯”。

## 实现边界

1. 扩展赛程提供方注册、日期同步、联赛别名解析和前端比赛筛选。
2. 保持 `league_data_pipeline.SUPPORTED_LEAGUES`、积分榜和三联赛回测范围不变。
3. 保持现有比赛详情接口通用；有 API-Football 外部赛事 ID 时继续按需获取证据。
4. 不为足协杯新增积分榜或虚构缺失的球队、球员数据。

## 验证

- 适配器映射测试覆盖联赛 ID、中文展示名和筛选别名。
- API 过滤测试覆盖 `league=cfa_cup` 不再返回 400。
- 前端 TypeScript 检查确保新筛选项不污染积分榜和回测筛选类型。
