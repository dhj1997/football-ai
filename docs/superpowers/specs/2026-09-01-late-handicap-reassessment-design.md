# 晚到亚洲让球盘口重算设计

## 问题

赔率同步可能晚于 GPT 预测。此时预测已经保存 1X2 概率和预期进球，但因生成时没有盘口，
`asian_handicap` 为空，详情页和 Portfolio 不会评估后来出现的让球市场。

## 方案

在市场评估层增加只读派生重算：当最新赔率含让球线和两侧赔率，而冻结预测没有相同盘口的
结算分布时，使用预测中已保存的主客队预期进球生成 Poisson 得分矩阵，按最新让球线计算主队
结算分布，并映射出主队/客队覆盖概率。随后沿用现有去水、Edge、EV、数据质量、赔率新鲜度和
风险限额规则进入 Portfolio。

原始预测记录、GPT 输出和预测时间戳保持不变；重算结果只存在于当前详情响应的派生决策中，
不会重复调用模型，也不会把赔率信息倒灌进模型概率。

## 失败处理与边界

预期进球缺失、非正数或盘口线无效时，不生成让球市场，继续使用现有 1X2 逻辑。已有且与
最新盘口线一致的预测结算分布优先使用模型提供的让球覆盖概率；仅在缺失或线不一致时使用
Poisson 重算，并标记 `probability_source=poisson_late_handicap`。

## 验证

增加市场评估测试，验证晚到盘口可从预期进球生成让球市场、覆盖率与 EV 可进入候选，并验证
盘口线变更不会复用旧结算分布。运行市场决策、Portfolio 及 API 相关测试，并检查阿森纳比赛
详情的让球候选。
