# P17 — Football AI Platform

最终平台由 Research Terminal、Competition Center、Match Center、Team Center、Prediction Engine、Model Lab、Backtest Lab、Explainability、Research Engine、Data Platform、Admin、API 组成。

目标不是堆功能，而是形成：Data → Feature → Prediction → Explanation → Evaluation → Research → Improvement 的闭环。

平台所有模块共享 Competition、Provenance、Versioning、Point-in-time 和 Evaluation 语义。
