# P14 Acceptance
- [ ] ResearchRun is immutable and reproducible.
- [ ] Dataset fingerprint and all versions are stored.
- [ ] Jobs are idempotent and locked.
- [ ] Retry does not duplicate predictions/reports.
- [ ] Leakage audit is mandatory.
- [ ] Statistical uncertainty and limitations are reported.
- [ ] Exploratory/confirmatory status is explicit.
- [ ] Reports are traceable to source run.
