# UI Redesign Master Plan

## Mission
Redesign the existing frontend into a cohesive Football Intelligence Platform.

## Non-Negotiable Constraints
Do not modify backend contracts, database models, prediction logic, evidence rules, automation semantics, or route behavior unless explicitly required by an existing project instruction.

Do not invent fake statistics, evidence, odds, lineups, injuries, or model results.

## Required Reading
Read `AGENTS.md`, `PRODUCT.md`, `DESIGN.md`, and the relevant task document before editing.

## Workflow Per Task
1. Inspect existing implementation.
2. Identify reusable components and current styling conventions.
3. Write a short implementation plan.
4. Implement only the requested scope.
5. Run relevant checks.
6. Summarize changed files and verification results.
7. Stop.
