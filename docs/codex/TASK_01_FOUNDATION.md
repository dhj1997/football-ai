# TASK 01 — UI Foundation

## Goal
Establish one coherent visual foundation using the existing frontend styling architecture.

## Read
- `AGENTS.md`
- `DESIGN.md`
- `docs/ui/DESIGN_SYSTEM.md`

## Work
Inspect `apps/web` and determine:
- framework and routing
- current CSS/token system
- global layout
- existing UI primitives

Then consolidate or extend:
- semantic colors
- typography scale
- spacing
- radii
- borders
- focus states
- status styles

## Constraints
- do not replace the whole styling stack
- do not add a UI library unless already required by project conventions
- do not redesign business pages yet

## Done When
Existing pages still render correctly and the foundation can be reused by later tasks.
