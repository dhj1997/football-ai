# TASK 08 — Admin and Automation

## Goal
Make operational status easier to inspect and manual actions safer.

## Required UI
- freshness/health summary
- automation job cards or table
- last run
- next run when available
- status
- failure/partial result visibility
- clear manual-run feedback

## Security
Do not expose server-side keys, secrets or admin credentials in browser code.

Preserve the existing backend authorization model.
