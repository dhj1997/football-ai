# TASK 02 — Shared Components

## Goal
Create or improve reusable frontend primitives before page-level redesign.

## Target Components
Adapt to the actual codebase; do not force these exact filenames:
- PageHeader
- SectionHeader
- Card / Panel
- Metric / StatCard
- StatusBadge
- Tabs
- Filter controls
- EmptyState
- LoadingState
- ErrorState
- Data freshness indicator

## Rules
- reuse existing components first
- preserve current API/data props when practical
- keep domain logic out of presentational primitives
- support keyboard and loading states

## Verification
Run the project's frontend lint/type/build checks defined in repository documentation.
