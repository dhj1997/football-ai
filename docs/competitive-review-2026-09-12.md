# 竞品对比与优化研究报告（2026-09-12）

调研对象：Sofascore、FotMob、Flashscore（国际主流体育数据产品）、懂球帝（国内）、以及公开的足球预测方法论（学术综述与开源系统）。目的：找出本产品的不足、可借鉴的 AI 预测逻辑与排版布局模式。

## 一、对比发现：我们的不足与优势

### 不足（按可弥补程度排序）

| # | 差距 | 竞品做法 | 我们的现状 | 可行性 |
| --- | --- | --- | --- | --- |
| 1 | **预测准确率透明化** | FotMob 每场比赛旁展示"模型预测历史命中率 %"，用户对预测有信任锚点 | 有全局模型评估页，但比赛详情页看不到"这个模型最近 N 场命中多少" | 高：结算表里已有数据，聚合后挂到比赛页即可 |
| 2 | **多模型一致性信号** | 学术界共识：单一模型易过拟合，集成（ensemble）更稳 | 双模型 + 泊松基线已存在，但只并列展示，没有"三方一致 → 提高置信"的信号 | 高：纯前端聚合，已有数据 |
| 3 | **Elo 评级特征缺失** | Elo-seeded Dixon-Coles 是近年公开研究的标准架构（SSRN 2026） | 基线只有市场先验收缩 + Dixon-Coles 修正，没有球队 Elo 演化值 | 中：积分榜历史数据可自算 Elo，作为基线特征注入 |
| 4 | **实时比赛体验** | Sofascore 势头图（Attack Momentum）、实时球员评分是招牌功能 | 比赛页无进行中内容，只有 5 分钟一次的比分同步 | 低：需要逐分钟事件流，免费数据源不支持 |
| 5 | **xG（预期进球）** | FotMob 主推实时 xG；xG 比历史进球更能反映实力（误差 ±0.3 球/场） | 无射门级数据，无法计算真 xG | 低：免费源无射门位置数据；可用"近 N 场射门/射正"做粗代理 |
| 6 | **提醒触达** | 竞品都有开赛/首发/比分推送 | 完全没有通知机制 | 中：网页端可做 PWA 推送，依赖用户授权 |

### 优势（竞品普遍没有的）

1. **CLV（收盘价比较）作为北极星指标**——多数公开预测产品只展示命中率，我们把"是否长期跑赢收盘价"做成了质量门禁，这在方法论上是领先的。
2. **执行层风控**——概率收缩、EV/Edge 双门槛、赔率新鲜度、当日联赛限额，公开预测网站几乎没有这层。
3. **全链路可追溯**——证据快照 + 决策审计 + 结算记录，竞品是黑盒输出概率，我们能回答"为什么这场不下"。

## 二、AI 预测逻辑借鉴（调研结论）

学术界与开源系统的共识架构（准确率上限约 55%–62%，接近市场基准）：

- **泊松/Dixon-Coles**：经典基线，DC 修正低比分相依性（我们已实现 ✓）
- **Elo 评级**：动态反映球队实力演化，常用作 DC 的先验种子（我们缺失）
- **xG 特征**：射门质量数据训练的 ML 模型（免费源不可得，暂缓）
- **梯度提升集成**（XGBoost/LightGBM）：在结构化特征上稳定优于单模型
- **市场概率收缩**：把模型概率向市场混合防过度自信（我们已实现 ✓，0.20）

**对本产品的启示**：我们的差异化是"LLM 阅读结构化证据 + 保守执行"，短期最有性价比的升级不是换模型，而是：①注入 Elo 特征丰富基线；②把"模型间一致性"变成显式信号（三方一致时历史命中率显著更高，这是免费的准确率提升）。

## 三、排版布局借鉴

- **比赛页 Tab 结构**：Sofascore（总览/阵容/统计/交锋/积分/预测）与我们（研究报告/模型明细/状态/交锋/阵容/赔率/球队）同构，无需大改；差异在**总览首屏**——竞品用"比分牌 + 势头图 + 概率条"三件套抓眼球，我们首屏是概率卡 + 建议，可加一条"市场对照条"（模型概率 vs 市场隐含概率并排）。
- **概率呈现**：竞品统一用"横条 + 百分比 + 预测结果徽章（1/X/2）"，识别成本最低；我们已有横条，补结果徽章即可。
- **列表密度**：Flashscore 单行极简（时间 + 队名 + 比分），详情全部进二级页；我们单行含三个徽章偏重，可把徽章折叠为小圆点（悬停展开）。

## 四、落地优先级建议

| 优先级 | 事项 | 工作量 |
| --- | --- | --- |
| P0 | 比赛页展示"模型近 30 场命中率"徽章（数据已有） | 小 |
| P0 | 概率卡补"预测结果徽章"（主胜/平/客胜高亮） | 小 |
| P1 | 模型一致性信号：三方（两 LLM + 基线）一致时标注"高一致" | 中 |
| P1 | 首屏市场对照条：模型概率 vs 市场隐含概率 | 小 |
| P2 | Elo 评级：从积分榜历史自算，注入基线先验 | 大 |
| P2 | 列表徽章折叠为圆点 | 小 |
| P3 | PWA 推送提醒（开赛/首发确认） | 大 |
| 不做 | 势头图、实时球员评分、真 xG（数据源不可得/成本过高） | — |
